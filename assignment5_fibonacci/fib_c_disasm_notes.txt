作业 5：C 版本反汇编注释
========================================

反汇编命令：
  dumpbin /disasm fib_c.obj > fib_c_obj_disasm.txt

编译参数：cl /nologo /Od /MT /FA fib_c.c
（/Od 关优化，这样 C 和汇编的对应关系看得清楚一些）

fib_c.c 里的递归函数：

  unsigned short memo[101][6];
  unsigned char done[101];

  void fib(int n)
  {
      int i, carry;
      if (done[n]) return;
      if (n <= 1) {
          memo[n][0] = (unsigned short)n;
          for (i = 1; i < 6; i++) memo[n][i] = 0;
          done[n] = 1;
          return;
      }
      fib(n - 1);
      fib(n - 2);
      carry = 0;
      for (i = 0; i < 6; i++) {
          int t = memo[n-1][i] + memo[n-2][i] + carry;
          carry = 0;
          if (t >= 10000) { t -= 10000; carry = 1; }
          memo[n][i] = (unsigned short)t;
      }
      done[n] = 1;
  }

main 里调用 fib / print_fib：

  02EE: E8 00 00 00 00     call fib
  0303: E8 00 00 00 00     call print_fib

说明：
1. x64 下第一个整型参数走 ecx，函数入口先把 ecx 存到 [rsp+8]（返回地址上面）。
2. 一进来 sub rsp,38h，加上返回地址 8 字节，每层栈帧 64 字节。
   16 位汇编版每层只要 16 字节，差别主要在于 64 位寄存器、对齐和 /Od 下把局部变量全放在栈上。
3. 递归两处 call fib 就是 C 里的 fib(n-1) 和 fib(n-2)，返回后从 memo 里取数相加。
4. 0x2710 = 10000，就是万进制的判断；减 10000 置进位，和汇编里的 cmp/jb/sub 一样。
5. 数组下标都是“基址 + n*12 + i*2”，12 是因为一行有 6 个 unsigned short。
