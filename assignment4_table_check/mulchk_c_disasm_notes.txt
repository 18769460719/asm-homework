    static int check_table(const unsigned char table[9][9], const char *label)
    {
        int errors = 0;
        int row;
        int col;
        for (row = 1; row <= 9; row++) {
            for (col = 1; col <= 9; col++) {
                if (table[row - 1][col - 1] != row * col) {
                    printf("%d %d    error\n", row, col);
                    errors++;
                }
            }
        }
        return errors;
    }

Global vs local conclusion:
    Global table:
        - has static storage duration
        - lives in the CONST segment
        - initialized once at program load
        - does not increase main's stack frame
    Local table:
        - has automatic storage duration
        - lives inside main's stack frame
        - initialized every time main runs
        - increases stack allocation and produces the long sequence of byte stores

Verification:
