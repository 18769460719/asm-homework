# 第三次作业：求和

## 作业要求

1. 计算 `1 + 2 + ... + 100`，把结果 `5050` 输出到屏幕。
2. 演示结果分别放在寄存器、数据段和栈中的操作。
3. 输入 `1~100` 内的整数 N，计算并输出 `1 + 2 + ... + N`。
4. 使用 C 语言实现，并查看反汇编代码、添加注释。

## 文件说明

### 基础题

- `sum.asm`：基础题源码。
- `bin/SUM.EXE`：已经汇编、链接并运行验证的 DOS 可执行文件。

程序先在 `AX` 中循环累加，然后分别演示：

```asm
mov bx,ax        ; 结果保留在寄存器 BX
mov sum_data,ax  ; 结果放入数据段
push ax          ; 结果压入栈
```

运行输出：

```text
5050
```

### 用户输入

- `sumin.asm`：输入版源码，文件名满足 DOS 8.3 限制。
- `bin/SUMIN.EXE`：已经汇编、链接并运行验证的 DOS 可执行文件。

程序使用 DOS `INT 21H` 的 `0AH` 号功能读取数字字符串，支持：

- 输入范围检查：只接受 `1~100`
- 空输入、非数字、`0`、`101`、`1000` 等错误输入会自动提示重输
- 反复除以 10 取余数，再按逆序输出十进制各位

运行示例：

```text
Input N (1-100): 100
Sum(1..N) = 5050
```

### C 语言与反汇编

- `sum_c.c`：C 语言源码。
- `sum_c_compiler.asm`：Microsoft C 编译器生成的完整汇编清单。
- `sum_c_disasm_notes.txt`：`main` 函数的真实反汇编及逐条注释。
- `bin/sum_c.exe`：已经编译并运行验证的 Windows x64 程序。

C 程序输出：

```text
5050
```

## DOSBox 中重新汇编

将 DOSBox 的工作目录映射到本目录，然后执行：

```dos
masm sum.asm;
link sum.obj;
sum

masm sumin.asm;
link sumin.obj;
sumin
```

注意：MASM 5.0 使用 DOS 8.3 文件名，因此输入版源码使用
`sumin.asm`，不能改成 `sum_input.asm`。

## 验证结果

- `SUM.EXE`：输出 `5050`
- `SUMIN.EXE`：输入 `1`、`10`、`100` 时分别输出 `1`、`55`、`5050`
- 异常输入自测：空输入、`0`、`101`、`1000`、非数字均被正确拒绝，内部自测结果为 `PASS`
- C 程序：输出 `5050`
